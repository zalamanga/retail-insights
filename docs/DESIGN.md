# Retail Insights design

Reading this as: an analyst's sales review for hiring reviewers and business readers, with the light, orderly work-application direction previously chosen by the user. ENERGY 2 / RHYTHM 2 / MOTION 1.

The main task is to explain what contributes to recorded sales, then inspect customer behavior and exclusions. The interface is an analysis workbook, with functional views for sales, customers and source quality. It is not a marketing landing page.

| Decision | Reason |
| --- | --- |
| Warm paper surfaces and dark forest ink | Keep a long financial review readable while connecting the page to a retail ledger. |
| Deep green accent | Identify the current analysis view and positive recorded amounts. |
| Dark rust for credits and negative amounts | Give the adjustment side of the accounting relationship its own semantic color, with explicit text and signs. |
| System sans-serif labels and Georgia headline figures | Preserve readable controls without font downloads; distinguish the financial answer from the supporting table. |
| Tabular numbers and right-aligned amounts | Let readers compare amounts as they would in a ledger. |
| One large net-sales figure followed by three smaller measures | Make the gross-minus-credits relationship readable before the charts. |
| A wide monthly chart and narrower country ranking | Give time coverage the most space, while showing geographic concentration beside it. |
| Full-width product table and cohort matrix | Preserve the row/column relationships rather than turning each result into a card. |
| Responsive, labelled scroll regions for tables | Keep all data reachable on narrow screens and at enlarged text sizes. |
| Static charts with hover/focus states only | Avoid moving values while someone is interpreting them. |
| Fixed light theme | Follow the user's earlier explicit preference for a light work application. |

Overview filters apply to sales and products only. Customer measures and cohorts have their own full-period view and visible scope. All amounts are GBP. Data is historical; this is not a live store. December 2011 is visibly partial. Country means the customer's recorded country, not a shipping destination.

Chart graphics are native SVG from the actual generated aggregates. The project uses text branding and real captured screenshots; it needs no stock illustration, logo, avatar or invented testimonial.
