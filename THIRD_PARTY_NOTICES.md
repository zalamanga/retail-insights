# Dataset attribution

This project uses Chen, D. (2015). **Online Retail** [Dataset]. UCI Machine Learning Repository. DOI: [10.24432/C5BW33](https://doi.org/10.24432/C5BW33). Original dataset: <https://archive.ics.uci.edu/dataset/352/online+retail>.

The dataset is distributed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The public CSV and JSON aggregates in this repository are derived from it. Changes include exact-row deduplication, an explicit merchandise policy, price normalization, exclusion accounting, aggregation and descriptive customer analysis. The original data covers December 2010 through 9 December 2011 and uses GBP. The author and UCI do not endorse this project.

The original workbook and customer-level processing database remain local. Public test fixtures are separately labelled synthetic data and are not the source of the portfolio findings.
